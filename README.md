# Python Sudoku Grid 🐍

A beginner-friendly Python project that draws a Sudoku-style grid using Turtle graphics and places random numbers inside it.

## 🎥 YouTube Tutorial

Watch the project on [BytePilot AI](https://www.youtube.com/@BytePilotHub2026).

## ✨ Features

- Draws a 9×9 grid using Python Turtle.
- Highlights the main grid borders and 3×3 sections.
- Places 15 random numbers in the grid.
- Avoids repeating numbers within the same row.

## 🛠️ Requirements

- Python 3
- Turtle (included with standard Python installations)

## ▶️ How to Run

Run the Python file:

```bash
python main.py
```

## 📚 Concepts Covered

- Python loops and conditionals
- Lists and sets
- Random number selection
- Turtle graphics

## 📝 Note

This project creates a Sudoku-style grid for learning purposes. It does not generate or validate a complete Sudoku puzzle.
